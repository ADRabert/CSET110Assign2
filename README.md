# CSET 110 Assignment 2: DOM Practice

## Assignment Info
This assignment combines what we've learned about creating websites & manipulating the DOM via JavaScript, and involves creating a fully working shopping cart system for a store page.

## Requirements
The shopping cart section should include the following working features:
- Adding items to the cart (image, name, price, quantity input & remove button)
- Calculating the total price from the items in the cart
- The ability to purchase all items in the cart, and clear the cart
- A check for if the selected item is already in the cart
